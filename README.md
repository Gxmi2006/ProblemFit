# ProblemFit

ProblemFit is a full-stack learning platform that helps beginner and intermediate programmers decide whether a coding problem fits their current knowledge.

The complete app lives in [`problemfit/`](problemfit/).

Start here:

- [ProblemFit README](problemfit/README.md)
- [Deployment guide](problemfit/docs/deployment.md)
- [GitHub Student Developer Pack setup](problemfit/docs/github-student-pack-setup.md)
- [Custom domain setup](problemfit/docs/custom-domain-setup.md)
- [Accuracy methodology](problemfit/docs/accuracy-methodology.md)

Local development:

```bash
cd problemfit/backend
python -m pytest -q

cd ../frontend
npm run build
```
